# استبدال شعار تقنية النسيم

## التعليمات:

1. **احفظ الصورة الأصلية للشعار** في هذا المجلد (`public`) باسم `logo.svg`

2. **إذا كانت الصورة بصيغة أخرى:**
   - PNG: احفظها باسم `logo.png`
   - JPG: احفظها باسم `logo.jpg`
   - SVG: احفظها باسم `logo.svg` (الأفضل)

3. **إذا استخدمت صيغة غير SVG:**
   - افتح ملف `components/Header.tsx`
   - غيّر السطر:
     ```tsx
     src="/nasim/logo.svg"
     ```
   - إلى:
     ```tsx
     src="/nasim/logo.png"  // أو logo.jpg حسب الصيغة
     ```

## ملاحظات مهمة:
- تأكد من أن اسم الملف يطابق المسار في `Header.tsx`
- الصورة ستظهر بأبعاد 120x60 بكسل
- استخدم صيغة SVG للحصول على أفضل جودة

---

**بعد حفظ الصورة الأصلية، ستظهر في الموقع تلقائياً.**
