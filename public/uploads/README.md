# مجلد الوسائط

هذا المجلد يحتوي على جميع الصور والملفات المستخدمة في الموقع.

## هيكل المجلد

- `/hero/` - صور البانر الرئيسي
- `/services/` - صور الخدمات
- `/portfolio/` - صور معرض الأعمال
- `/team/` - صور فريق العمل
- `/branding/` - الشعارات والهوية البصرية
- `/templates/` - صور القوالب
- `/blog/` - صور المقالات

## تنسيقات الصور المدعومة

- WebP (مفضل للأداء)
- JPEG
- PNG
- SVG (للشعارات والأيقونات)

## إرشادات الاستخدام

1. استخدم أسماء وصفية للملفات
2. أضف النص البديل (alt text) لجميع الصور
3. استخدم WebP للصور الكبيرة
4. احرص على ضغط الصور قبل الرفع
5. استخدم أبعاد مناسبة للاستخدام المطلوب

## أبعاد الصور الموصى بها

- صور البانر الرئيسي: 1920x1080
- صور الخدمات: 800x600
- صور معرض الأعمال: 600x400
- صور فريق العمل: 400x400
- الشعارات: 200x60
- صور المشاركة الاجتماعية: 1200x630
