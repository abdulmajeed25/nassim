# تقنية النسيم - صيانة مكيفات

موقع ويب متكامل لشركة صيانة مكيفات مع نظام إدارة محتوى متقدم.

## ✨ المميزات

- 🎨 واجهة مستخدم عربية حديثة وجذابة
- 📱 تصميم متجاوب لجميع الأجهزة
- 🚀 نظام إدارة محتوى متقدم (CMS)
- 🤖 ذكاء اصطناعي لتحسين المحتوى والأداء
- 📊 لوحة تحكم إدارية شاملة
- 🔧 نظام حجز الخدمات
- 📝 إدارة الصفحات والمنشورات
- 🖼️ مدير الوسائط المتقدم

## 🛠️ التقنيات المستخدمة

- **الواجهة الأمامية**: React 18 + TypeScript + Tailwind CSS
- **أداة البناء**: Vite
- **إدارة الحالة**: Zustand
- **أدوات الذكاء الاصطناعي**: تكامل مع OpenAI API
- **نظام إدارة المحتوى**: نظام كتل مخصص
- **التصميم**: Tailwind CSS + CSS Modules

## 🚀 التثبيت والتشغيل

### المتطلبات
- Node.js 18+
- npm أو yarn

### خطوات التثبيت
```bash
# استنساخ المشروع
git clone <رابط-المستودع>
cd nasim

# تثبيت التبعيات
npm install

# تشغيل في وضع التطوير
npm run dev

# بناء للإنتاج
npm run build

# فحص TypeScript
npm run type-check
```

## 📁 هيكل المشروع

```
src/
├── admin/          # لوحة التحكم الإدارية
├── ai/             # أدوات الذكاء الاصطناعي
├── blocks/         # نظام الكتل
├── components/     # المكونات الأساسية
├── dataGateway/    # بوابة البيانات
├── renderer/       # محرك العرض
├── store/          # إدارة الحالة
├── templates/      # قوالب الصفحات
└── types/          # تعريفات TypeScript
```

## 🤖 الذكاء الاصطناعي

المشروع يتضمن أدوات ذكاء اصطناعي متقدمة:

- **مولد القوالب**: إنشاء قوالب صفحات ذكية
- **محلل الأداء**: تحليل وتحسين أداء الموقع
- **محسن SEO**: تحسين محركات البحث
- **محلل سلوك المستخدم**: فهم وتحسين تجربة المستخدم
- **مولد المحتوى**: إنشاء محتوى عالي الجودة
